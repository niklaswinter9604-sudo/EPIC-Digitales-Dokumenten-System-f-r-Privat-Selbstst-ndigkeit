# UI-Referenz-Analyse

## Software-Referenz: clockin

Analyse der bestehenden Zeiterfassungssoftware als Referenz für das eigene Produktdesign.

---

## 1. Onboarding-Flow

### Digitalisierungsoptionen

**Bildschirm:** "Was möchtest du noch digitalisieren?"

Verfügbare Optionen:
- Urlaub
- Krankheiten & Abwesenheiten
- Schichtplanung
- Unternehmensanalyse
- Einsatzplanung
- Datenübertragung Steuerberater (DATEV)

**UX-Elemente:**
- Kontrollkästchen für jede Option
- Skip-Button am unteren Rand
- Fortschrittsbalken oben

### Zeiterfassungsoptionen

**Bildschirm:** Auswahl der Zeiterfassungsart

Optionen:
- Allgemeine Arbeitszeit (Kommen, Gehen & Pause) - Uhrsymbol
- Projektarbeitszeiten - Dokumentsymbol

### Branchenauswahl

**Bildschirm:** "In welcher Branche ist dein Unternehmen tätig?"

Optionen:
- Dienstleistungen
- Handwerk
- Gesundheit und Wellness
- Einkauf, Bestellen & Handel
- Hotel und Gastronomie
- Auto, Verkehr & Maschinen
- Andere Branche

## 3. Desktop-Dashboard (Bürocenter)

**Positionierung:** "Dein persönliches Bürocenter"
**Claim:** "Gewinne wieder den Überblick über dein Unternehmen"

### Sidebar-Navigation
- Dashboard
- Kalender
- Mitarbeiter
- Kunden
- Projekte
- Korrektur
- Analyse
- Einstellungen
- Support

### Dashboard-Module

| Modul | Beschreibung |
|-------|--------------|
| Puls (17) | Aktivitätsindikator mit Trendlinie |
| Neuigkeiten | Timeline mit Mitarbeiter-Events |
| LIVE-Übersicht: Mitarbeiter | Status aller Mitarbeiter mit Indikatoren |
| LIVE-Übersicht: Projekte | Aktive Projekte (z.B. "Installation Fußbodenheizung", "Badezimmersanierung") |
| Offene Anträge | Genehmigungsworkflow für Mitarbeiter |
| Abwesenheiten | Übersicht über Urlaub/Krankheit |

**Kernversprechen:**
- "Steuere dein Unternehmen vom Schreibtisch aus"
- Echtzeit-Informationen zusammengeführt
- Persönliches Cockpit für Überblick

## Strategische Abgrenzung zu unserem System

| clockin (Referenz) | Contextual Time Intelligence |
|--------------------|------------------------------|
| Manuelle Zeiterfassung | Automatische Erfassung |
| Branchenspezifisch | Wissensarbeiter-fokussiert |
| Reporting-orientiert | Entscheidungs-orientiert |
| Compliance-getrieben | Wertschöpfungs-getrieben |
| Kontrollinstrument | Selbstführungstool |

---

## Learnings für eigenes Design

1. **Onboarding:** Schrittweise Konfiguration mit Fortschrittsanzeige
2. **Modularität:** Funktionen in logische Kategorien gruppieren
3. **Dashboard:** Zentrales Steuerungscockpit als Einstiegspunkt
4. **Mobile-First:** App für standortunabhängige Nutzung
5. **Integration:** DATEV-Export als wichtiges Feature für deutsche Zielgruppe
