# Index zuerst

Summary: Ein Agent liest zuerst INDEX.md und öffnet nur die Notizen, deren Suchzeile zur Frage passt.

## Context

Die öffentliche Wissensbasis beantwortet, wie Dokumente abgelegt und gefunden werden. Sie enthält keine Fallinhalte.

## Details

Der Index ist eine Karte. Eine Notiz gehört erst zur Wissensbasis, wenn ihre Zeile in `INDEX.md` steht. Für eine Frage reichen in der Regel eine bis drei Notizen. Die verwendete Notiz wird mit ihrer `id` zitiert.
